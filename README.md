# Escape Room – Fuga dall'Egitto

Gioco 3D nel browser: 12 enigmi in un'ora, dall'Egitto fino al Mar Rosso.

Per giocare apri il link di GitHub Pages del repository (Settings → Pages).
I file vanno serviti da un sito web: aprendo `index.html` con un doppio clic dal computer il gioco non parte.

Struttura:
- `index.html` – pagina del gioco
- `js/` – codice (three.js r170 caricato da cdn.jsdelivr.net)
- `models/people/*.glb` – personaggi 3D (compressione meshopt, texture WebP)
- `models/*.json` – animali
- `tex/` – texture dell'ambiente
